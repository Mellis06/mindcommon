# Contributing to MINDCOMMON

Thank you for considering a contribution. This project is at an early research and prototype stage; careful documentation and critical feedback are as valuable as code.

## Good first contributions

- Improve plain-language explanations and accessibility.
- Review the architecture and threat model.
- Add tests using synthetic fixtures only.
- Identify governance assumptions that require community validation.
- Improve documentation of consent, withdrawal, access review, or benefit-sharing.

## Safety requirements

- Never submit real participant, patient, or mental-health information.
- Never commit credentials, API keys, private keys, database dumps, or environment files.
- Do not add diagnostic, triage, treatment, or clinical-decision features.
- Do not present a prototype control as a production security guarantee.
- Flag legal, ethics, safety, and governance assumptions instead of silently treating them as settled.

## Pull requests

Please explain the problem, the proposed change, relevant risks, how it was tested, and any assumptions requiring review. Prefer small, focused pull requests.
